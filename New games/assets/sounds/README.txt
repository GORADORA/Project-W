このフォルダに効果音・BGMのファイルを置くと、ゲーム中に自動で鳴ります。

■ 使い方
1. 下の一覧のファイル名で、音のファイルをこのフォルダに置く
2. ブラウザを再読み込みする
   → その場面で音が鳴るようになります(置いていない場面は鳴らないだけです)

■ ファイル名と鳴る場面
  click.mp3    … ボタンを押した時
  select.mp3   … カードを選んだ・掴んだ時
  play.mp3     … カードを出した時(中央に大きく表示される時)
  attack.mp3   … 対決を挑んだ時
  counter.mp3  … 反撃した時
  destroy.mp3  … 先生が撃破された時(対決以外:S9・5Cの昇格で自分の先生を撃破/S7・S8)
                 対決での撃破では鳴りません(勝ち負けの音だけが鳴ります)
  battle-win.mp3  … 対決に勝った時(「勝ち」のハンコが出る時)
                    交代で遊ぶ対戦では、どちらが勝ってもこの音
  battle-lose.mp3 … 対決に負けた時(コンピュータ・オンライン対戦で、自分の先生が負けた時)
                    ※相打ち・無効の時は、勝ち負けの音は鳴りません
  recover.mp3  … 職員室からカードを回収した時(2B・5C・S2)
  guard.mp3   … ガードで撃破を防いだ時
  draw.mp3     … カードを引いた時
  side.mp3     … サイドを獲得した時
  turn.mp3     … ターンが始まった時
  win.mp3      … 勝負がついた時
  bgm.mp3      … BGM(対戦中にくり返し流れる。教室のガヤガヤなど)
                 最初の画面のチェック、または対戦中の右上の「BGM」ボタンでオン・オフ
                 (効果音も同じく、対戦中の「効果音」ボタンでオン・オフできます)

■ ファイル名を変えずに使いたいとき
ダウンロードした素材の名前のまま使いたい場合は、js/data/sounds.js を開き、
その場面の file: '○○.mp3' の部分を、置いたファイルの名前に書き換えてください。
同じページで音量(volume:0〜1)も調整できます。

■ 形式
mp3 がおすすめです(wav / ogg も使えます。その場合は sounds.js のファイル名も合わせてください)。
